# Smart Forest Monitoring System: SRS, UML Design and Project Management

A Software Requirement Engineering team project at American International University-Bangladesh (AIUB). We specified an AI- and IoT-based platform that helps forest departments detect wildfires, illegal logging and poaching in real time, and keeps tourists and local communities informed through a mobile app.

## The problem and the idea

Traditional forest monitoring relies on manual patrols, which are slow and hard to scale across large forests. The proposed system combines **IoT sensors, GPS tracking, AI-based cameras, drones and a mobile app** into one platform that collects live data and sends instant alerts to the responsible authorities.

## What the specification covers

**Functional requirements**

1. User registration and authentication: hashed passwords, OTP recovery, multi-factor authentication and role-based access (administrator, forest officer, researcher)
2. Live dashboard: temperature, humidity, soil moisture and rainfall from IoT sensors over MQTT/HTTP, pushed to the UI in real time
3. Sensor management
4. Alerts and notifications
5. Data logging and reporting
6. Tourist safety features
7. Advanced monitoring technologies (AI cameras, drones)

**Design:** use case, class and activity diagrams (UML)

**Planning:** development plan and schedule, marketing plan (short-term, long-term, continuous), social impact, and cost and profit analysis

## Project management

The project was run with Agile practices and managed in **Asana**: workspace and member setup, tasks with assignees, dates, priority, status and dependencies, and a To Do / Doing / Done board. See [`Assignment on Project Management Tool.pdf`](Assignment%20on%20Project%20Management%20Tool.pdf).
